# AgritechSystemApp

A simple agritech dashboard with a lightweight Node.js backend and a static frontend.

## Backend

```bash
cd backend
npm install
npm start
```

The backend exposes health and crop endpoints at http://localhost:5000/api.

## Frontend

Open `frontend/index.html` in a browser or serve the folder locally:

```bash
cd frontend
python3 -m http.server 3000
```

Then visit http://localhost:3000.
